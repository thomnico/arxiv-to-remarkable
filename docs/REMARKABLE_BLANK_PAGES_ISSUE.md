# reMarkable EPUB Blank Pages Issue

## Problem

EPUBs generated by arxiv2rm display excessive blank pages on reMarkable devices. A 45-page PDF results in 200+ page EPUB on reMarkable, with approximately half the pages being blank.

**Observed**: 45-page PDF → 211-230 pages on reMarkable (half blank)
**Expected**: ~45-60 pages

The same EPUB renders correctly in other EPUB readers (Calibre, Apple Books, etc.).

## Attempted Fixes (All Unsuccessful)

### CSS Changes Made

1. **Line height**: Reduced from `2.0` to `1.4`
2. **Page breaks**: Removed `page-break-before: always` from `.chapter`
3. **Notes zone**: Set `.notes-zone { display: none }` (was `min-height: 20vh`)
4. **Background colors**: Removed all `background-color` properties
5. **Margins**: Reduced all margins significantly
6. **vh units**: Removed all viewport-relative units

None of these changes resolved the issue.

## Potential Solutions to Investigate

### 1. ~~KePub Format~~ (TESTED - DID NOT WORK)

Tested converting EPUB to KePub format using `kepubify`. The blank pages issue persisted on reMarkable.

```bash
# Tested on 2024-11-25
kepubify /tmp/nihms515946_v4.epub -o /tmp/nihms515946.kepub.epub
rmapi put /tmp/nihms515946.kepub.epub /genAI/
# Result: Same blank pages issue
```

**Conclusion**: KePub conversion does not fix the pagination problem. The issue is likely in the XHTML/CSS structure itself, not the EPUB format variant.

### 2. Compare with Known-Working EPUBs

Find EPUBs that render correctly on reMarkable and compare:
- XHTML structure
- CSS properties
- Metadata
- Manifest entries

### 3. Minimal CSS Test

Test with extremely minimal or no CSS to isolate the issue:
```css
body { margin: 0; padding: 0; }
p { margin: 0.5em 0; }
```

### 4. Font Embedding

Test without embedded OpenDyslexic font - font handling may affect pagination.

### 5. Paragraph Splitting

Review `_split_paragraphs()` in `epub_builder.py` - may be creating too many paragraph elements.

### 6. XHTML Structure

Check if chapter XHTML structure causes reflow issues:
- Nested divs
- Section/article tags
- Empty elements

## Technical Context

### reMarkable EPUB Rendering

- Uses Kobo-based reader software
- Limited CSS support compared to modern browsers
- E-ink optimized rendering may have pagination quirks
- Does not support all CSS3 properties

### Current EPUB Structure

```
EPUB/
├── content.opf
├── toc.ncx
├── nav.xhtml
├── stylesheet.css

```
